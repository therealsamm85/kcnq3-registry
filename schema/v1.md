## Controlled vocabularies

| Field | Allowed values |
|---|---|
| `subject.variant_type` | `missense_GoF`, `missense_LoF`, `missense_unknown`, `truncating`, `splice`, `deletion`, `duplication`, `regulatory`, `unknown` |
| `subject.age_years_bucket` | `0-1`, `1-2`, `2-3`, `3-5`, `5-7`, `7-10`, `10-13`, `13-18`, `18-30`, `30+` |
| `subject.sex` | `F`, `M`, `X`, `unknown` |
| `recording.duration_hours_bucket` | `<1`, `1-4`, `4-12`, `12-24`, `24-48`, `48+` |
| `recording.montage` | `10-20_monopolar`, `10-10_monopolar`, `10-20_bipolar`, `double_banana`, `other_monopolar`, `other_bipolar`, `unknown` |
| `findings.spindle_interpretation` | `below`, `in`, `above`, `no_age_provided`, `no_data` |
| `findings.activation_label` | `none`, `mild`, `moderate`, `strong` |
| `findings.quality_grade` | `A`, `B`, `C`, `D`, `unknown` |
| `intervention.type` | `medication`, `diet`, `stimulation`, `behavioral`, `other` |
| `intervention.record_kind` | `baseline`, `pre`, `post`, `followup` |

## Validators (regex)

| Field | Regex |
|---|---|
| `subject.variant_gene` | `^[A-Z][A-Z0-9]{1,15}$` |
| `subject.variant_protein` | `^p\.[A-Z][a-z]{2}\d{1,5}(?:[A-Z][a-z]{2}|\*|fs|del|dup)$` |
| `subject.country_region` | `^[A-Z]{2}$` (ISO 3166-1 alpha-2) |
| `submission_id` | uuid4 (8-4-4-4-12 lowercase hex with version+variant bits set) |
| `submitted_at_month` | `^\d{4}-(?:0[1-9]\|1[0-2])$` (no day) |

## Numeric ranges

| Field | Range |
|---|---|
| `findings.background_pdr_hz` | finite, typically 0.5–20 |
| `findings.csws_threshold_pct` | 0–100 |
| `findings.spindle_density_per_min_central` | ≥ 0, < 100 |
| `findings.activation_factor` | ≥ 0, < 10000 |
| `findings.morphology_events_per_min` | ≥ 0, < 10000 |
| `findings.morphology_spike_wave_pct` | 0–100 |
| `findings.swi_pct_by_stage.*` | 0–100 per stage |
| `findings.sleep_stages_pct.*` | 0–100 per stage |
| `findings.n_sleep_cycles` | int, 0–100 |
| `recording.n_channels` | int, 0–256 |

## Limits

- `intervention.name` ≤ 64 chars
- Any string value anywhere in the submission: ≤ 80 chars (enforced by
  PHI scanner)
