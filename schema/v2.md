# Registry schema v2

Authoritative definition lives in
[`scripts/_lib_schema.py`](../scripts/_lib_schema.py). This document
is a human-readable companion.

Schema v2 is an **additive** bump over v1. All v1 submissions remain
valid. The new Tier-2 fields are optional — a submission may include
any or none of them.

## v2 controlled vocabularies (new fields only)

See [v1.md](./v1.md) for all v1 vocabularies — they remain unchanged.

### Coupling (spindle–slow-wave phase-amplitude coupling)

| Field | Allowed values |
|---|---|
| `findings.coupling_plv_bucket` | `<0.1`, `0.1-0.2`, `0.2-0.35`, `0.35-0.5`, `>0.5` |
| `findings.coupling_preferred_phase_octant` | `[-180,-135)`, `[-135,-90)`, `[-90,-45)`, `[-45,0)`, `[0,45)`, `[45,90)`, `[90,135)`, `[135,180]` |
| `findings.coupling_n_events_bucket` | `<10`, `10-50`, `50-200`, `>200` |
| `findings.coupling_rayleigh_significant` | `true` / `false` (bool) |

### Slow waves

| Field | Allowed values |
|---|---|
| `findings.sw_density_bucket` | `<5`, `5-15`, `15-30`, `30-50`, `>50` |
| `findings.sw_mean_ptp_bucket` | `<75`, `75-150`, `150-250`, `>250` |
| `findings.sw_method` | `yasa`, `heuristic` |

### HFOs (high-frequency oscillations)

| Field | Allowed values |
|---|---|
| `findings.hfo_rate_bucket` | `0`, `<1`, `1-5`, `5-15`, `>15` |
| `findings.hfo_available` | `true` / `false` (bool) |
| `findings.hfo_pct_on_spike_bucket` | `<10`, `10-50`, `50-90`, `>90` |

### IEDs (interictal epileptiform discharges)

| Field | Allowed values |
|---|---|
| `findings.ied_method` | `external_spikenet`, `ensemble_heuristic`, `unavailable` |
| `findings.ied_rate_bucket` | `0`, `<1`, `1-5`, `5-15`, `15-50`, `>50` |
| `findings.ied_nrem_rate_bucket` | `0`, `<1`, `1-5`, `5-15`, `15-50`, `>50` |
| `findings.ied_age_flag` | `ok`, `drift_warning`, `untested` |
| `findings.ied_agreement_bucket` | `<50`, `50-75`, `75-90`, `>90` |
| `findings.ied_n_rolandic_benign_bucket` | `0`, `small`, `medium`, `large` |

## Aggregator behaviour

The aggregator publishes count distributions for all v2 categorical
fields once a cell reaches n ≥ 5 (K_MIN). Bool fields (`coupling_rayleigh_significant`,
`hfo_available`) are counted as `"true"` / `"false"` string keys.

Mixed v1/v2 registries aggregate correctly — v1 submissions simply
contribute `null` for any v2 field they don't carry, and those
submissions are skipped for per-field counts.

## Backward compatibility

A submission with `schema_version: 1` validates successfully against
the registry validator. The v1/v2 dual-accept logic lives in
`_lib_validate.py`.

## Interpretation caveats

These fields are descriptive/exploratory. Interpret registry distributions
with the following limitations in mind:

- **Slow waves:** no validated pediatric normative ranges exist for the
  bucket values reported here. Distributions are descriptive only and
  should not be used for clinical reference ranges.
- **HFOs:** scalp-EEG HFO normative ranges are not established for
  pediatric populations. `hfo_rate_bucket` and `hfo_pct_on_spike_bucket`
  are research metrics; registry distributions reflect whatever detection
  method the submitter used.
- **Coupling (SO–spindle):** spindle–slow oscillation coupling matures
  through adolescence. A lower PLV at age 5 is developmentally normal.
  Cross-cohort comparison without age stratification is misleading.
- **IED ensemble heuristic:** `ied_method: ensemble_heuristic` is a
  rule-based detector, not a validated ML model. The
  `external_spikenet` path is currently stubbed. Agreement percentages
  (`ied_agreement_bucket`) reflect internal ensemble consistency, not
  expert inter-rater reliability.
